# 키우미 (kiosk-helper)

**누구나 부담 없이 키오스크를 연습할 수 있는 키오스크 이용 연습 서비스**

## 1. 프로젝트 소개

키오스크는 일상생활 곳곳에서 활용되고 있지만, 디지털 기기 사용 경험이나 숙련도에 따라 이용에 어려움을 겪는 사람들이 있습니다.
'키우미'는 누구나 시간적·심리적 부담 없이 키오스크 이용 과정을 연습할 수 있도록 돕는 서비스입니다.
다양한 키오스크 환경을 가상으로 체험하고 반복적으로 연습함으로써 디지털 경험의 차이를 좁히고, 누구나 디지털 사회의 편리함을 누릴 수 있도록 하는 것을 목표로 합니다.

## 2. 주요 기능

### 키오스크 카테고리
- 패스트푸드
- 카페
- 음식점
- 마트·편의점

### 연습 모드

**튜토리얼 모드**
- 단계별 안내와 설명을 통해 키오스크 이용 방법 학습
- 주요 조작 요소를 강조하여 직관적인 사용 지원

**자유 연습 모드**
- 정해진 조건 없이 원하는 상품과 옵션을 자유롭게 선택
- 실제 주문과 유사한 과정 연습

**미션 모드**
- 주어진 주문 조건에 맞춰 키오스크 이용
- Easy·Hard 난이도 별 모드 제공
- 주문 및 결제 완료 후 최종 수행 결과 확인

## 3. 기대 효과

- **이용자:** 반복 연습을 통한 키오스크 이용 자신감 향상 및 디지털 접근성 확대
- **업체:** 주문 관련 문의 감소 기대
- **사회:** 디지털 경험의 격차 완화

## 4. 기술 스택

- Frontend: HTML5, CSS3, JavaScript
- Backend: Python, FastAPI, SQLite
- Design: Figma Make

## 6. 실행 방법

### 1. 프로젝트 다운로드

```bash
git clone https://github.com/jeong45/kiosk-helper.git
cd kiosk-helper
```

### 2. 백엔드 실행

필요한 Python 패키지를 설치한 후 다음 명령어로 서버를 실행합니다.

```bash
cd backend
python -m uvicorn app.main:app --reload
```

-> 백엔드 서버 실행 후 다음 주소에서 API 문서를 확인할 수 있습니다.
-> API 문서: http://127.0.0.1:8000/docs

### 3. 프론트엔드 실행

1) VS Code에서 프로젝트 폴더를 엽니다.
2) Live Server 확장 프로그램을 설치합니다.
3) frontend/splash/inde.html 파일을 엽니다.
4) 마우스 오른쪽 버튼을 클릭하여 Open with Live Server를 선택합니다.

### 4. 서비스 이용

1) 연습할 키오스크 카테고리를 선택합니다.
2) 튜토리얼, 자유 연습, 미션 모드 중 하나를 선택합니다.
3) 상품 선택부터 결제까지 키오스크 이용 과정을 연습합니다.
4) 미션 모드에서는 주문 완료 후 수행 결과를 확인할 수 있습니다.
